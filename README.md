# SpaceX SPCX Custom Like Animation Player 🚀

这是一个用于在线展示与测试 SpaceX 在 X (Twitter) 上线的高级交互式点赞动画播放器。

## 📖 项目简介
2026年6月12日，SpaceX 以股票代码 `SPCX` 正式在纳斯达克挂牌上市。X (Twitter) 官方特此上线了定制的 Hashflag 点赞活动。本项目提取了该活动的 Lottie 动效配置（`SpaceXCustomLikeFinal_sakura_0.json`），并使用轻量级 Lottie-web 渲染器还原了完整的动效细节。

## 🔗 在线预览
部署于 GitHub Pages 的在线体验地址：
[https://tech-melon.github.io/spcx-like-animation/](https://tech-melon.github.io/spcx-like-animation/)

## 🎨 特色与设计
* **Starship（星舰）原型**：动画中的火箭长宽比约为 `5.5:1`，并带有精致的镜面不锈钢反光材质，完美复刻星舰特征。
* **Sakura 樱花粉色调**：采用了限定的粉色配色方案，红心爆裂为粉色星光并伴随粉色尾焰升空。
* **纯矢量渲染**：基于 HTML5 SVG 渲染，无损缩放且极其轻量（动画配置仅约 99 KB）。

## 🛠️ 技术栈
* **动效引擎**：[Lottie-web](https://github.com/airbnb/lottie-web) (cdnjs 托管)
* **核心结构**：HTML5 / Vanilla CSS / Modern ES6 Javascript
* **数据格式**：Lottie JSON (`spcx.json`)
